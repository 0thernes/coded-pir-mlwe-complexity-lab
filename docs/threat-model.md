# Threat Model & Verification Trust Boundary (`docs/threat-model.md`)

Because `coded-pir-mlwe-complexity-lab` is a formal verification and scientific research repository (not a networked service), the primary threats are **proof soundness compromise**, **statement-vs-claim drift**, **memory corruption / parser denial-of-service in native C11 and Eshkol verifiers**, **client-side script/XSS exposure in GitHub Pages**, and **supply-chain / artifact tampering**.

| Threat | Attack Vector | Mitigation in This Repository | Residual Risk |
|---|---|---|---|
| **Proof Cheating / Unsound Axiom** | Hidden `sorry`, `admit`, `native_decide`, `Lean.trustCompiler`, custom `axiom`, or unaudited private lemma | Zero-Mathlib Lean 4.35.0; `lake build --wfail`; source-level forbidden-token grep in CI; `VerifyAxioms.lean` (37 decls); programmatic `AuditExhaustiveAxioms.lean` walking **all 2,306 `TriadFrontier.*` declarations** under `module` via `Lean.collectAxioms`; independent 6-kernel replay via `lake comparator --config comparator.json --paranoid` (`lean`, `leanchecker-paranoid`, `lean4lean`, `nanoda`, `con-leche` 5,711 decls, `con-ron` 5,711 decls); live negative kernel-rejection tamper gate | Shared bug across all 6 independent kernels (negligible) |
| **Vacuous Theorem Statements** | Uninhabited algebraic typeclasses (`SimpleField`, `CommRing`) making universal quantifiers vacuously true | Concrete non-degenerate inhabitants proved in `lean/TriadFrontier/NonVacuity.lean` (`SimpleField (Fin 2)` char-2, `SimpleField (Fin 3)`, `SimpleField (Fin 5)`, `SimpleField (Fin 11)`, `SimpleField (Fin 101)` in `PIRF101Cert.lean`, non-degenerate concurrent & coplanar $\mathbb{P}^3(\mathbb{F}_5)$ 4-line witnesses, `T1i`/`T1k`/`T2e`–`T2i` concrete witnesses, `CommRing Int`, anti-periodic $D=3$, `MPoly (Fin 2) 1`, conference/self-complement witnesses, 2-var Boolean XOR, 3-rep LDC) + **11 universal negative boundary refutations** (`AdversarialTests.lean`, incl. `adv_blaser_refutes_rank_71_at_m6`) | Semantic misinterpretation by reader (mitigated by `docs/statement-fidelity.md`) |
| **README / Paper / Schema Drift** | Paper, README, links, or `repo.yaml` diverging from kernel-checked statements or Build Standard | Automated CI parity check `scripts/check_readme_axioms.py`; Draft 2020-12 `repo.yaml` validation against `repo-standard.schema.json`; automated zero-broken-link scan across all `.md` files & Blueprint nodes; single-version-source test in `tests/test_all.py` | Manual prose nuances outside automated checks |
| **C11 Undefined Behavior / Buffer Overflow** | Stack buffer over-write (`eta > 7`, `K > 8`), signed `m*D` overflow, or unchecked `atoi`/`atof` CLI args | Strict `-std=c11 -Wall -Wextra -Wpedantic -Werror`; explicit defensive bounds in `triad_core.c`; strict `strtol`/`strtod` range-checked CLI parsers returning exit `2`; **90 unit tests** (incl. live $\mathbb{F}_{101}$ $(6,3,3)$ PIR encode/decode) + **1,024-iteration fuzz** (`fuzz_triad.c`); Ubuntu CI AddressSanitizer + UndefinedBehaviorSanitizer | Host compiler bugs |
| **Eshkol AD Parser DoS / Silent `NaN`** | Unclosed strings/parens, deep recursion, zero-division, or `Math.abs(NaN) > tol === false` | `MAX_PARSE_DEPTH=256`, `MAX_EVAL_DEPTH=256`, `MAX_EVAL_STEPS=100000`, strict finite-domain guards, and explicit `Number.isFinite` assertions in `eshkol/run_eshkol_ad.mjs` (7/7 negative guards tested in `pytest`) | JS runtime engine bugs |
| **Pages UI XSS / External Tracking** | Third-party CDN compromise or untrusted script execution on GitHub Pages | Zero external CDN dependencies; strict `<meta http-equiv="Content-Security-Policy" content="default-src 'none'; ...">` on `docs/site/index.html` and `docs/site/blueprint.html`; WCAG AA keyboard accessibility | GitHub Pages infrastructure compromise |
| **Artifact Tampering Post-Build** | Altered PDF, arXiv tarball, Lean source, test suite, or witness JSON | Complete LF `MANIFEST.sha256` hashing ALL canonical proof/code/test/script/paper/figure/data files (incl. all 25 `.lean` files); **dual timestamps** (`data/MANIFEST.sha256.tsr` DigiCert RFC 3161 verified cryptographically via `openssl ts -verify -CAfile` + `data/MANIFEST.sha256.ots` 3-calendar Bitcoin OpenTimestamps) with manifest & signature tamper tests in CI; GitHub Actions Sigstore SLSA `attest-build-provenance@v4`; Software Heritage permanent SWHID; immutable registration in `0thernes-research-archive` (`0TH-2026-012`) | Compromise of GitHub account credentials |
| **Misuse of C11 Utilities in Production Crypto** | Treating research verification helpers as side-channel-hardened FIPS 140-3 crypto | Explicit non-production disclaimers in `LIMITATIONS.md`, `SECURITY.md`, and `docs/SUBMISSION_PACKET.md` | User ignoring documentation |
